# Полоска ЭЦН

Источник данных:

```text
backend/data/reference/artificial_lift.xlsx
```

Файл скопирован из `WellsArtificialLiftBig.xlsx`, лист `Скважинное оборудование`.

Backend endpoint:

```text
GET /api/wells/{well_id}/artificial-lift
```

Правила отображения:

- начало отрезка - `Дата монтажа`;
- окончание отрезка - `Дата демонтажа`;
- если `Дата демонтажа` пустая, frontend показывает отрезок до конца доступного графика и в hover выводит `—`;
- если `Цель спуска` начинается с `Фонтанная`, подпись отрезка - `Воронка`;
- иначе подпись берется из столбца `T` (`Тип ГНО`).

Для не-фонтанных спусков hover на полоске показывает:

- `Дата отказа`;
- `Причина подъема`;
- `Габарит УЭЦН`;
- `Ном. Произв. м3/сут`;
- `Тип Газосепаратора`;
- `Мощность, кВт для ПЭД`.
