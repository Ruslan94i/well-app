# Мониторинг ТР

Источник: `Мониторинг ТР (17.03.2026).xls`, лист `Лист1`.

Для runtime в проект добавлен извлеченный CSV:

```text
backend/data/reference/tr_monitoring.csv
```

В CSV сохранены строки начиная с `2024-11-01`, чтобы график мог показывать ТР за два месяца до старта текущей телеметрии и не уходил раньше ноября 2024.

Backend endpoint:

```text
GET /api/wells/{well_id}/tr-monitoring
```

Поля ТР на графике:

- `Р пл`
- `Н д`
- `Р на приёме`
- `Рзаб`
- `Q нефти`
- `Q жидкости`
- `Вода`
- `Рнас`
- `ГФ`
- `Кпр`

Frontend отображает эти ряды как штриховые ступенчатые линии. По умолчанию они выключены в списке параметров.
