# Промпт для Codex — переработать страницу «Настройка модели»

## Цель страницы (одно предложение)
Дать пользователю подобрать параметры авторазметки для **одной скважины, месторождения или произвольного набора скважин (в т.ч. из разных месторождений)**, оценить качество по кнопке пересчёта и **выгрузить параметры в JSON** для применения в классификаторе.

## Что НЕ трогать
- Центральный график, нижние дорожки (Авторазметка / Разметка вручную), левый сайдбар «Параметры» и «Отображаемые параметры» — оставить на местах и как есть.
- Расположение блоков: слева категории+слайдеры, по центру график, справа панель результатов — сохранить.
- Левый сайдбар уже содержит выбор скважины и месторождения — **дублирующий выбор на этой странице не добавлять**, кроме режима мультивыбора (см. ниже).

## 1. Шапка — убрать дублирующий текст
Сейчас три перекрывающихся сообщения. Заменить на **один заголовок + одну строку**:

```
Настройка модели
Подберите параметры авторазметки для скважины или группы, оцените качество и выгрузите для классификатора.
```

Удалить тексты: «Настройка правил авторазметки: параметры наследуются…», «Настройка модели авторазметки», «Правила можно подбирать для одной скважины или группы. Центральный график использует те же параметры…».

## 2. Область модели — единый селектор (переформатировать под групповую модель)
Сейчас область задаётся в ДВУХ местах сразу — чипы «Группа: Все / Ic / Vt…» и плашка «ОДНА СКВАЖИНА / ГРУППА СКВАЖИН». Это дублирует друг друга и путает. **Свести в один контрол** «Область модели» — сегментированный переключатель из трёх режимов:

```
Область модели:  [ Одна скважина ]  [ Месторождение ]  [ Групповая модель ]
```

Правило группировки: **ID скважины = `<Месторождение>_<номер>`** (`Ic_359` → месторождение `Ic`, префикс до первого `_`).

1. **Одна скважина** — берётся из левого сайдбара. Месторождение подсвечивается автоматически (`Ic_359` → `Ic`). Под переключателем — строка «Скважина Ic_359 · месторождение Ic».
2. **Месторождение** — выпадающий список месторождений (строить **динамически** из префиксов, не хардкодить). Параметры применяются ко всем скважинам месторождения. Строка: «Месторождение Ic · N скважин».
3. **Групповая модель (новый режим)** — **конструктор группы**:
   - Поле «Название группы» (например `Осложнённый фонд Vt+Ic`).
   - Кнопка «Добавить скважины» → модалка: список всех скважин, сгруппированных по месторождению, чекбоксы + поиск; можно отмечать скважины **из разных месторождений**.
   - Выбранные скважины — чипами с крестиком (удалить). Счётчик «N скважин из M месторождений».
   - Одна правка параметров применяется ко **всем** скважинам группы; качество усредняется по группе.

Приоритет наследования: **скважина > групповая модель > месторождение > Все скважины (дефолты)**.

## 3. Карточки категорий (рендерить ДИНАМИЧЕСКИ из схемы)
Список категорий и их параметры брать из JSON-схемы (раздел 7), **не хардкодить**. Каждая карточка:
- Заголовок категории.
- **Одна** строка описания простыми словами.
- Маленький блок псевдо-правила (как сейчас у «Работа/Остановка») — опционально, из поля `rule` схемы.
- 1–4 слайдера. Для каждого слайдера: подпись, **короткое описание простыми словами под подписью**, текущее значение, диапазон (`min`–`max`), шаг, единица. Значения слайдеров **жёстко ограничены** диапазоном из схемы — это и есть «безопасные» границы, чтобы модель не развалилась.
- Чип «Совпадение X% → Y%» (до/после) — обновляется только после пересчёта (раздел 5).

Кнопка «Сбросить» в шапке карточек — вернуть дефолты схемы для выбранной области.

## 4. Кнопки действий — убрать дубли, оставить 3 понятные
Сейчас кнопок слишком много и они дублируются: «Сбросить», «Сохранить настройки» (сверху), «Запустить авторазметку» (сверху), снова «Сохранить настройки» (в панели), «Применить и пересчитать», «Что изменилось». **Свести к трём действиям в одном месте (правая панель), с подписью-смыслом под каждой.** Верхний ряд кнопок над графиком убрать.

1. **Пересчитать качество** (основная, синяя) — прогнать классификатор с текущими параметрами по выбранной области и обновить «ДО→ПОСЛЕ» (раздел 5). Подпись: «прогнать модель и сравнить с ручной разметкой».
2. **Сохранить и выгрузить** (вторичная, активна после пересчёта) — сохранить параметры области на бэкенд **и** скачать `model_overrides.json` (раздел 6) одним действием. Подпись: «сохранить параметры и выгрузить JSON для классификатора».
3. **Сбросить** (третичная, текстовая ссылка) — вернуть параметры к дефолтам области. Подпись: «вернуть значения по умолчанию».

«Что изменилось» — не отдельная кнопка, а **раскрывающаяся строка** (аккордеон) под оценкой: список изменённых параметров «ключ: было → стало». До пересчёта пустая/свёрнута.

## 5. Оценка качества (панель «Результаты адаптации»)
Считать **только по нажатию «Пересчитать качество»** (не в реальном времени).
- **ДО ИЗМЕНЕНИЙ** — % совпадения авторазметки с ручной разметкой (`target_*`) на текущих сохранённых параметрах.
- **ПОСЛЕ ИЗМЕНЕНИЙ** — то же на параметрах из слайдеров.
- Метрика совпадения: доля суток, где авто-метка категории совпала с ручной (по дорожкам `auto_target_*` vs `target_*`), усреднённая по выбранным скважинам. Для месторождения/групповой модели — среднее по скважинам области.
- **КАЧЕСТВО ПО ГРУППАМ** — раскрыть: совпадение по каждой категории отдельно (до→после), чтобы видеть, какую категорию правка улучшила/ухудшила.

Бэкенд: эндпоинт пересчёта принимает `{scope, overrides}` и возвращает `{overall_before, overall_after, by_category:{...}}`. **Никакого пересчёта на каждый сдвиг слайдера** — только по кнопке.

## 6. Формат выгрузки `model_overrides.json` (контракт для классификатора)
```json
{
  "model_version": "episode_rules_v10_2",
  "created_at": "<UTC ISO>",
  "scopes": {
    "all":    { /* переопределения для всех */ },
    "fields": { "Ic": { "kprod_pulse_drop_cyclic": 0.04 } },
    "wells":  { "Ic_359": { "snizh_win_drop": 4.0 } },
    "sets":   { "set_1": { "wells": ["Ic_359","Vt_410"], "params": { "wct_trend_pp": 2.5 } } }
  }
}
```
Применение в классификаторе (приоритет wells > fields > all; набор приравнивается к перечисленным скважинам):
```python
P = {**PARAMS, **scopes["all"],
     **scopes["fields"].get(field, {}),
     **scopes["wells"].get(well, {})}
episodes = run_all(tele_df, vsp_df, wells=[well], P=P)
```
`run_all`/`WellCtx` уже принимают `P=PARAMS` — нужно лишь прокинуть пер-скважинный `P`. В `compute_episodes.py` (батч-раннер) добавить опцию `--overrides model_overrides.json` и собирать `P` по скважине, как выше. Ключи в JSON = ключи `PARAMS`; значения вне диапазонов схемы клампить.

## 8. Критерии приёмки
- Шапка — один заголовок + одна строка; старые три текста удалены.
- Область модели задаётся **одним** контролом (старое дублирование «Группа»-чипы + плашка «ОДНА/ГРУППА СКВАЖИН» убрано). `Ic_359` сразу подсвечивает `Ic`.
- Режим «Групповая модель» позволяет собрать набор скважин из разных месторождений, назвать группу и применить параметры ко всем.
- В правой панели **три** действия с понятными подписями: «Пересчитать качество», «Сохранить и выгрузить», «Сбросить». Верхний ряд кнопок над графиком и дубль «Сохранить настройки» убраны. «Что изменилось» — раскрывающаяся строка, не кнопка.
- Все категории из схемы отрендерены карточками со слайдерами и простыми описаниями; значения клампятся диапазоном.
- «ДО/ПОСЛЕ» и «Качество по группам» обновляются **только** по «Пересчитать качество».
- «Сохранить и выгрузить» отдаёт `model_overrides.json` по контракту (раздел 6); классификатор умеет его применять (`--overrides`).
- График, дорожки и левый сайдбар не изменились.
