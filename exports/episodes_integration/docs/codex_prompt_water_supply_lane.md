# Промпт для фронта — лейн «Увеличение подачи воды» на треке разметки

## Что нужно
Добавить на трек «Авторазметка» новую дорожку **«Увеличение подачи воды»** (флаг),
рядом с СППВ. Это новая категория авторазметки (v10.2): резкий рост подачи воды.

## Откуда данные (НИЧЕГО не считать на фронте)
Категорию уже формирует алгоритм авторазметки и кладёт в выходные данные двумя способами:
1. **Поэпизодно** — в таблице `episodes` строки с `label = "Увеличение подачи воды"`
   (поля `start`, `end`, `confidence_tier`, `explanation`). Рисовать как интервальные метки
   на новой дорожке (как остальные категории трека «Авторазметка»).
2. **Построчно** — колонка `auto_target_water_supply_up` = `1.0` на сутках-флагах
   (формируется `compute_episodes.py --enrich`). Если трек строится из построчных
   `auto_target_*`, добавить эту колонку в маппинг дорожек.

Семантика правила (для подсказки/легенды, на фронте не вычисляется): суточная подача воды
(СППВ / `telemetry_bdpv_volume_rate`) выросла более чем на **20%** относительно предыдущих
суток; нулевые сутки в сравнении не участвуют.

## Изменения во фронте
1. **Реестр категорий трека «Авторазметка»**: добавить запись
   `{ key: "water_supply_up", label: "Увеличение подачи воды", short: "↑Вода", color: <свободный цвет> }`.
   Лучше строить список дорожек **динамически** из данных (по уникальным `label` в `episodes` /
   по присутствующим `auto_target_*`), чтобы будущие категории не требовали правок кода.
2. **Рендер дорожки**: те же примитивы, что для прочих категорий (интервалы по `start`/`end`
   из `episodes`, либо построчная заливка по `auto_target_water_supply_up == "1.0"`).
3. **Тултип/клик**: показывать `explanation` соответствующего эпизода (как у остальных категорий).
4. **Легенда**: добавить пункт с тем же цветом.

## Чего НЕ делать
- Не вычислять правило на клиенте и не дёргать пересчёт — только отображение готовых данных.
- Не хардкодить полный список дорожек, если возможно — рендерить из данных.

## Критерии приёмки
- На треке «Авторазметка» появляется дорожка «Увеличение подачи воды» с интервалами там,
  где `episodes.label == "Увеличение подачи воды"`.
- Клик/наведение показывает `explanation`.
- Легенда содержит новую категорию; добавление ещё одной категории в будущем не требует правок
  (если реализован динамический реестр).
