# Безопасные пороги авторазметки — для Codex

Что отдаём пользователю на странице «Настройка модели»: по каждой из 15 категорий — **простое описание, как она определяется**, и **1–2 параметра**, которые можно двигать в безопасных границах. Ключи = ключи словаря `PARAMS` в `episode_rules_v10_2.py`. Значения вне `[min,max]` бэкенд клампит. Остальные параметры пользователю не показываем (их трогать опасно).

## 15 категорий

«Окно времени» — за какой период измеряется порог (важно: «5 бар» без окна бессмысленно). Окна фиксированы в детекторе и пользователю не показываются (кроме обводнённости, где окно — тоже ползунок); в таблице приведены, чтобы подпись к ползунку была корректной.

## Связка с бэкендом и пересчёт по заданным настройкам

Классификатор — `episode_rules_v10_2.py`. Точка входа: `run_all(tele_df, vsp_df, wells=None, P=PARAMS)`. Параметры берутся **только** из `P`. Значит, чтобы пересчитать «по настройкам пользователя», достаточно подменить `P`:

```python
import episode_rules_v10_2 as er

SAFE = {  # из JSON выше: key -> (min, max, default)
    "stop_freq_hz": (0.5, 15, 5.0), "long_stop_h": (2, 48, 12),
    # ... все 21 ключ ...
}

def clamp_overrides(raw: dict) -> dict:
    out = {}
    for k, v in (raw or {}).items():
        if k in SAFE:
            lo, hi, _ = SAFE[k]
            out[k] = min(max(float(v), lo), hi)
    return out   # незнакомые ключи отбрасываем -> модель не сломать

def effective_params(field: str, well: str, scopes: dict) -> dict:
    # приоритет: скважина > группа(набор) > месторождение > all > дефолты
    P = dict(er.PARAMS)
    for layer in (scopes.get("all"), scopes.get("fields", {}).get(field),
                  _set_for(well, scopes), scopes.get("wells", {}).get(well)):
        if layer:
            P.update(clamp_overrides(layer))
    return P

def recompute_well(tele_df, vsp_df, well, P) -> pd.DataFrame:
    return er.run_all(tele_df, vsp_df, wells=[well], P=P)   # эпизоды этой скважины
```

### Метрика «ДО / ПОСЛЕ» (совпадение с ручной разметкой)
Построчно сравниваем авто-дорожки `auto_target_*` с ручными `target_*` (маппинг метка→колонка уже есть в `compute_episodes.py: LABEL_TO_AUTO`). Совпадение = доля суток, где значения равны, усреднённая по категориям и по скважинам области.

```python
from compute_episodes import LABEL_TO_AUTO, attach_auto_target

def agreement(tele_df, episodes_df, wells) -> dict:
    enr = attach_auto_target(tele_df, episodes_df)          # заполняет auto_target_* из эпизодов
    by_cat = {}
    for label, (auto_col, val) in LABEL_TO_AUTO.items():
        man_col = auto_col.replace("auto_target_", "target_")
        if man_col not in enr or auto_col not in enr:
            continue
        m = enr[enr["well_id"].isin(wells)]
        same = (m[auto_col].fillna("") == m[man_col].fillna("")).mean()
        by_cat[label] = round(float(same) * 100, 1)
    overall = round(sum(by_cat.values()) / max(len(by_cat), 1), 1)
    return {"overall": overall, "by_category": by_cat}
```

### Эндпоинт (по кнопке «Пересчитать качество», НЕ на каждый сдвиг ползунка)
```
POST /api/automark/recompute
body: { "scope": {"type":"well|field|set", "field":"Ic", "well":"Ic_359", "wells":[...]},
        "overrides": { "<param_key>": <value>, ... } }      # текущие ползунки

resp: { "overall_before": 41.0, "overall_after": 44.0,
        "by_category_before": {...}, "by_category_after": {...} }
```
Логика:
1. `wells` = по scope (одна / все скважины месторождения / набор).
2. **before** = `agreement(tele, episodes_saved, wells)` на СОХРАНЁННЫХ параметрах.
3. **after** = для каждой скважины `P = effective_params(...)` с `overrides`, `recompute_well`, затем `agreement`.
4. Усреднить по скважинам, вернуть overall + by_category для обоих.
- Тяжёлый прогон — офлайн/по кнопке; кэшировать «before» (сохранённые параметры меняются только при «Сохранить»).

### Сохранение и выгрузка
Кнопка «Сохранить и выгрузить» пишет/отдаёт `model_overrides.json`:
```json
{ "model_version":"episode_rules_v10_2",
  "scopes": { "all":{}, "fields":{"Ic":{...}}, "wells":{"Ic_359":{...}},
              "sets":{"<имя группы>":{"wells":[...],"params":{...}}} } }
```
Батч-раннер `compute_episodes.py` принимает `--overrides model_overrides.json` и собирает `P` по скважине через `effective_params(...)` перед `run_all`. Так одни и те же настройки работают и в превью на странице, и в проде.

## Главное
- Пользователь меняет только параметры из таблицы, в их границах → модель не разваливается.
- Пересчёт = подмена `P` в существующем `run_all`, новый код детекторов писать не нужно.
- «ДО/ПОСЛЕ» считается только по кнопке, сравнением `auto_target_*` с `target_*`.
